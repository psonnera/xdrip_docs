xDrip prend en charge les montres Pebble d'origine (abandonnées en 2016) comme les nouveaux modèles Pebble relancés en 2025 (Pebble 2 Duo, Pebble Time 2).

Après avoir appairé votre Pebble avec votre téléphone, vous pouvez l'activer dans xDrip.

::: xdripitem Intégration de la montre Pebble <span class='symbol'><img src="../images/ON.png" style="zoom:75%;" /></span>
:::

xDrip installera alors lui-même le cadran (inutile de le télécharger).

<img src="./images/M-S-SW3b.png" style="zoom:75%;" />

Il proposera aussi d'installer l'application du bouton de mise en veille ; si vous l'avez ignorée, vous pourrez l'installer plus tard avec Installer Pebble Apps, en bas de la page.

<img src="./images/M-S-SW3c.png" style="zoom:75%;" />

Vous pouvez choisir différents cadrans.

::: xdripitem Choisir le Cadran Pebble
:::

<img src="./images/M-S-SW3e.png" style="zoom:75%;" />

## Nouveaux modèles Pebble (depuis 2025) {#new-pebble-models-2025-onwards}

Sélectionnez le cadran Pebble Trend Clay Version (All Models) ([xDrip-Pebble-E](https://github.com/jstevensog/xDrip-Pebble-E)). Il fonctionne sur tous les modèles Pebble, anciens et nouveaux, en couleurs sur les montres couleur, y compris la nouvelle Pebble Time 2.

## Anciens modèles Pebble {#legacy-pebble-models}

Avec les versions récentes d'Android, utiliser une ancienne montre Pebble est [compliqué](https://www.reddit.com/r/pebble/comments/1776bbx/installing_pebble_apk_on_fresh_android_14_setup/). Utilisez les ressources de [Rebble](https://rebble.io/).

Les cadrans Standard, Color Trend et Pebble Classic Trend ont été conçus pour les modèles Pebble d'origine. Le cadran Pebble Trend Clay Version (All Models) fonctionne aussi sur les anciens modèles.
