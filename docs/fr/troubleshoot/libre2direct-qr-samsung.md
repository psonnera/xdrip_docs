# Importer une sélection de paramètres Bluetooth pour Libre 2 Direct sur les téléphones SAMSUNG {#importing-selected-bluetooth-settings-for-libre-2-direct-for-samsung-phones}

<img src="./images/qr_libre2direct_samsung.png" style="zoom:60%;" />

Scannez le QR code ci-dessus pour charger les paramètres nécessaires au Libre 2 en direct. Dans Paramètres du menu « hamburger » de gauche, sélectionnez « Configuration automatique » et scannez le QR code. Vous devrez appuyer sur le bouton Oui pour confirmer l'importation de ces paramètres.

# Paramètres Libre 2 Direct importés depuis le QR code... {#libre-2-direct-settings-imported-from-qr-code}

Le scan du QR code ne modifie que les 3 paramètres suivants. 

Paramètres moins courants/Paramètres Bluetooth/Utiliser le scan = false
   
Paramètres moins courants/Paramètres Bluetooth/Faire confiance à Auto-Connect = false
    
Paramètres moins courants/Paramètres Bluetooth/Utiliser les scans en arrière-plan = false
