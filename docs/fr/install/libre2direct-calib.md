# Importer les paramètres du Libre 2 direct AVEC étalonnage {#importing-settings-for-libre-2-direct-with-calibration}

<img src="./images/qr_libre2direct-calib.png" style="zoom:60%;" />

Scannez le QR code affiché ici pour charger les paramètres nécessaires au Libre 2 direct. Dans Paramètres du menu « hamburger » de gauche, sélectionnez « Configuration automatique » et scannez le QR code. Appuyez ensuite sur le bouton Oui pour confirmer l'importation de ces paramètres.

## Paramètres du Libre 2 direct importés par le QR code... {#libre-2-direct-settings-imported-from-qr-code}

Le scan du QR code applique les paramètres et valeurs ci-dessous.
Ce sont les modifications de paramètres nécessaires au bon fonctionnement du Libre 2 direct.

- Source de données matérielle = Libre Bluetooth
- Fonctionnalités de scan NFC → Utiliser la fonction NFC = activé
- Fonctionnalités de scan NFC → Démarrage de la connexion Bluetooth avec les capteurs Libre2 = Toujours se connecter aux capteurs Libre2
- Fonctionnalités de scan NFC → Utiliser la méthode de lecture multibloc plus rapide = désactivé
- Fonctionnalités de scan NFC → Utiliser la méthode de lecture optimisée pour toute balise = désactivé
- Paramètres moins courants → Paramètres avancés pour Libre 2 → Afficher les valeurs brutes dans le graphique = activé
- Paramètres moins courants → Paramètres avancés pour Libre 2 → Afficher les informations du capteur dans statut = activé
- Paramètres moins courants → Autres options diverses → Algorithme Libre hors processus = désactivé
- Paramètres moins courants → Autres options diverses → Calibration par algorithme OOP2 = Calibrate based on raw
- Paramètres moins courants → Autres options diverses → Lissage des données Libre = activé
- Paramètres moins courants → Autres options diverses → Récupérer l'historique du Freestyle Libre = activé
- Paramètres moins courants → Paramètres Bluetooth → Activer le Bluetooth = activé
- Paramètres moins courants → Paramètres Bluetooth → Permettre la dissociation du BluCon = activé
- Paramètres moins courants → Paramètres Bluetooth → Garde-fou Bluetooth = activé
- Paramètres moins courants → Paramètres Bluetooth → Faire confiance à Auto-Connect = activé
- Paramètres moins courants → Paramètres Bluetooth → Utiliser les scans en arrière-plan = activé
- Paramètres moins courants → Paramètres Bluetooth → Fermer GATT sur déconnexion BLE = désactivé
