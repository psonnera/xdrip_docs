::: warning Ancien xDrip Sync
En juillet 2024, Google a arrêté l'[API Firebase](https://firebase.google.com/docs/cloud-messaging/migrate-v1) obsolète qu'utilisait xDrip Sync.  
Mettez xDrip à jour vers une version du [23 juillet 2024](https://github.com/NightscoutFoundation/xDrip/releases/tag/2024.07.23) ou plus récente pour utiliser l'ancienne méthode de synchronisation.  
Il est recommandé de mettre xDrip à jour au moins vers la dernière version publiée (release).
:::

Sélectionnez cette source de données si vous avez configuré un appareil avec xDrip comme principal et décidé que cet autre appareil serait l'abonné.  
L'appareil principal est généralement celui qui reçoit la glycémie du capteur.  
Un abonné reproduit en temps réel les valeurs de l'appareil principal (au délai réseau près).

Le nombre d'appareils xDrip abonnés est pratiquement illimité.

Voir [ici](../use/syncsetup) comment configurer l'abonné xDrip Sync.
