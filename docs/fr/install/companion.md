Si vous utilisez l'application du fabricant, xDrip peut récupérer les données du capteur depuis celle-ci.

Cette fonction est disponible pour :

- les applications G6/G7 (principal uniquement)
- les applications ONE/ONE+ et Stelo (uniquement si l'application affiche des notifications de glycémie)
- l'application CamAPS (y compris la version canadienne)
- les applications Guardian, MiniMed, Simplera
- les applications Eversense
- les applications Micro tech Aidex, LinX Vista, Equil G
- les applications Micro tech Diaexpert (Allemagne) et Smart 2 (Brésil)
- l'application GlucoRx Vixxa (Inde)
- les applications Ottai Sens et Tag
- l'application Pasta
- les applications CareSens et iCan (Sinocare)
- l'application Vitatok
- l'application Glucotech
- l'application SiSensing Eco (Chine)
- l'application Diabeloop DBLG2

Pour les applications Omnipod 5 et MiniMed Mobile (EU), xDrip lit aussi l'insuline active (IoB) dans la notification de l'application compagnon lorsqu'elle est disponible. Pour MiniMed Mobile (EU), cela fonctionne quelle que soit la langue de l'application.

Pour utiliser cette fonction, vous **devez** autoriser xDrip à accéder aux notifications.

xDrip n'utilisera cet accès à aucune autre fin que la lecture de la valeur de glycémie dans les notifications.

::: xdripitem Veuillez autoriser les permissions


Une autorisation est nécessaire pour recevoir les données d'autres applications. xDrip ne fait rien d'autre que recevoir. Veuillez activer xDrip sur l'écran suivant  

  &emsp;&emsp;&emsp;&emsp;&emsp;<span style="background-color: white; color: black;">&ensp;OK&ensp;</span>
:::

Si vous ne pouvez pas autoriser l'accès aux notifications, ouvrez le menu à trois points dans les paramètres de l'application et choisissez Autoriser les paramètres restreints.

<img src="./images/Companion6.png" style="zoom:78%;" />

<br>

Vous recevrez des données dans xDrip lorsqu'elles sont disponibles dans l'application et que les notifications de l'application sont visibles sur le téléphone.

Si aucune donnée n'apparaît et qu'aucun message d'erreur ne s'affiche, vous devrez peut-être [Démarrer le capteur](../use/startsensor#followers-and-companion-apps).
