### Créez votre propre application {#build-your-own-app}

Vous pouvez créer votre propre application à l'aide de ce [formulaire](https://docs.google.com/forms/d/e/1FAIpQLScD76G0Y-BlL4tZljaFkjlwuqhT83QlFM5v6ZEfO7gCU98iJQ/viewform).

La diffusion vers xDrip n'est possible qu'avec les capteurs G6.

<img src="./images/byoda.png" style="zoom:75%;" />

Si aucune donnée n'apparaît et qu'aucun message d'erreur ne s'affiche, vous devrez peut-être [Démarrer le capteur](../use/startsensor#followers-and-companion-apps).
