Pour obtenir les données de la pompe, vous devez la connecter au lecteur de glycémie Bluetooth avec un câble USB OTG.

<img src="./images/DS-M6xx.png" style="zoom:50%;" />

Suivez [ces](https://github.com/pazaan/600SeriesAndroidUploader) instructions.

Activez la diffusion vers xDrip dans l'application d'envoi (uploader).

<img src="./images/600up1.png" style="zoom:75%;" />

<img src="./images/600up2.png" style="zoom:75%;" />

Si aucune donnée n'apparaît et qu'aucun message d'erreur ne s'affiche, vous devrez peut-être [Démarrer le capteur](../use/startsensor#followers-and-companion-apps).

<br>

Pour les développeurs, la documentation technique de l'intent de diffusion se trouve [ici](https://github.com/NightscoutFoundation/xDrip/blob/master/Documentation/technical/Incoming_Glucose_Broadcast.md).
