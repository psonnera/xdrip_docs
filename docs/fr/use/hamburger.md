De nombreux éléments peuvent être ajoutés à ce menu ; par défaut, vous y trouverez les suivants :

**Écran d'accueil** revient simplement à l'écran principal.

[**État du système**](../troubleshoot/systemstatus) affiche des informations internes sur votre source de données, le partage et l'état de la montre.

[**Mise en veille Alertes**](./alarms#snooze-alert) vous propose des options pour mettre en veille ou désactiver les alertes.

[**Statistiques**](./statistics) fournit des statistiques de base.

[**Historique**](#history) vous permet de parcourir les données des jours précédents.

[**Paramètres**](./settings) ouvre le menu des paramètres.

Le menu peut aussi afficher d'autres entrées si vous ajoutez des éléments ou lorsque vous utilisez un capteur :  
vous verrez les actions sur le capteur si xDrip est directement connecté à un capteur, ainsi que sur un abonné xDrip Sync si le téléphone principal l'est.

**[Démarrer le capteur](./startsensor)** ou **[Arrêter le capteur](./stopsensor)** : avant d'utiliser ces fonctions, consultez la section correspondant à votre [capteur](../install/datasource#sensor-selection).

::: warning Attention
Un abonné xDrip Sync peut transmettre à distance le démarrage ou l'arrêt du capteur (si le capteur le permet) et les étalonnages.  
Soyez extrêmement prudent si vous utilisez ces fonctions sur un abonné alors que le xDrip principal accepte les actions des abonnés.
:::

Pour les transmetteurs Bluetooth ([Libre](../install/libreBT)), vous verrez aussi **Scan Bluetooth**.

**Alertes de niveau** s'affiche si cette option est activée dans [Alarmes et alertes](./alarms#glucose-level-alerts-list).

**Tableau de données de glycémie**, **Graphe de calibration** et **Tableau de calibrations** doivent être [ajoutés](./lesscommon) manuellement si vous utilisez l'[algorithme d'étalonnage de xDrip](../calibrate/calibrate#native-and-xdrip-algorithms).

### Historique {#history}

Lorsque vous utilisez xDrip depuis un certain temps, l'historique vous permet de parcourir les anciennes données.

::: xdripitem Historique
:::

1. parcourir le ou les jours précédents
2. parcourir le ou les jours suivants
3. définir le nombre de jours affichés à l'écran (de 1 à 14)
4. activer ou désactiver les statistiques
