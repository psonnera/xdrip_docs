La détection de mouvement sert à détecter le mode véhicule et à ajouter des fonctions lorsque vous conduisez votre voiture.

::: xdripitem Activer la Détection de Mouvement<span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Utiliser les capteurs pour détecter les types de mouvement
:::

Vous pouvez suivre les mouvements sur votre graphique principal.

::: xdripitem Loguer et grapher les déplacements <span class='symbol'><img src="../images/EN.png" style="zoom:75%;" /></span>
&ensp;Stocker les types de mouvement récents et les tracer sur le graphique principal
:::

<img src="./images/M-S-MT3a.png" style="zoom:75%;" />

Comme pour la synchronisation xDrip, vous pouvez définir quel téléphone envoie réellement les informations de mouvement : ce sera le maître du mouvement, et un seul appareil peut être maître. Vous pouvez configurer un appareil comme abonné du mouvement pour surveiller à distance les mouvements de l'appareil maître.

::: xdripitem Utiliser les données de mouvement distantes <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
&ensp;Données de mouvement prises à distance plutôt que depuis le téléphone local
:::

::: xdripitem Agir comme maître du mouvement <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
&ensp;Être maître des données de mouvement, même si nous sommes un Abonné. Ne positionner que sur un seul appareil !
:::

Le mode véhicule active d'autres options.

::: xdripitem Activer le Mode Véhicule<span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Lorsqu'un véhicule est détecté, activer des fonctionnalités supplémentaires
:::

<img src="./images/M-S-MT5a.png" style="zoom:75%;" />

Vous pouvez activer automatiquement le mode véhicule lors de la connexion au système audio Bluetooth de votre voiture.  
Vous pouvez aussi le configurer manuellement en identifiant la connexion Bluetooth audio de votre voiture.

::: xdripitem Détecter l'audio de la voiture<span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Activer automatiquement le mode véhicule quand connecté au Bluetooth de la voiture
:::

::: xdripitem Découvrir l'audio de la voiture actuelle
&ensp;Taper pour définir le périphérique audio de voiture actuellement connecté
:::

Augmenter le seuil d'alarme basse vous permet d'être prévenu à un niveau plus élevé que celui défini dans les alarmes.

::: xdripitem Augmenter le seuil 'Bas' <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
&ensp;Augmenter le niveau à partir duquel les alarmes Basses se déclencheront en mode véhicule
:::

xDrip peut activer automatiquement l'annonce vocale des valeurs lorsque vous conduisez.

::: xdripitem Prononcer les valeurs <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
&ensp;Activer la fonction de prononciation des valeurs en mode véhicule
:::

Vous pouvez faire jouer un son lors du passage en mode véhicule, ainsi qu'un son de rappel toutes les 90 minutes. 

::: xdripitem Jouer le son <span class='symbol'><img src="../images/EN.png" style="zoom:75%;" /></span>
&ensp;Son de notification lorsque le mode véhicule est détecté
:::

::: xdripitem Répéter le son <span class='symbol'><img src="../images/EN.png" style="zoom:75%;" /></span>
&ensp;Répéter le son de notification toutes les 90 minutes si toujours en mode véhicule
:::
