##### Lissage du graphique {#graph-smoothing}

::: xdripitem Lissage du graphique
:::

Le lissage du graphique applique un filtre de lissage au graphique pour le rendre plus facile à suivre (moins de bruit).

Il s'agit uniquement d'un effet visuel, sans impact sur les valeurs. 

::: xdripitem Activer <span class='symbol'><img src="../images/EN.png" style="zoom:75%;" /></span>
Simplifier les graphiques en lissant les irrégularités des lectures précédentes. La lecture actuelle, les alertes et la valeur de diffusion ne sont pas affectées par ce paramètre.
:::

<img src="./images/M-S-DS6aa9b.png" style="zoom:76%;" />  

<img src="./images/M-S-DS6aa9c.png" style="zoom:76%;" />

::: xdripitem Afficher non-lissées <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
Afficher les données non lissées même si le lissage du graphique est activé. Si le plugin d'étalonnage est utilisé, les données non lissées (au lieu des données du plugin) seront affichées.
:::

##### Réécriture de l'historique {#rewrite-history}

Assurez-vous qu'elle est aussi activée sur les abonnés, pour éviter un affichage différent des glycémies passées.

&ensp;Après le calibrage, ajustez le graphique brut récent pour lisser à la nouvelle calibration

##### Axe Y {#y-axis}

L'axe vertical de l'écran principal a par défaut un minimum de 40 mg/dl (2,22 mmol/l) et un maximum de 250 mg/dl (13,9 mmol/l).

Vous pouvez fixer librement les valeurs basse et haute de l'axe Y.

::: xdripitem Personnaliser la plage de l'axe y
:::

Par défaut, lorsque des valeurs sortent de cette plage, le graphique l'élargit temporairement pour les rendre visibles, puis revient à vos valeurs fixes une fois ces valeurs sorties de l'écran.

Si vous préférez garder une plage fixe pour l'axe Y et faire défiler le graphique verticalement au lieu de l'élargir, activez Auto-pan Y-axis.

::: xdripitem Auto-pan Y-axis <span class='symbol'><img src="../images/EN.png" style="zoom:75%;" /></span>
&ensp;Enable: Pan the graph with a fixed Y-axis range (minimum-maximum) to show out-of-range readings.  
&ensp;Disable: Expand the Y-axis range to include out-of-range readings.
:::

### Aperçu de l'assistant de bolus {#bolus-wizard-preview}
