Si votre téléphone prend en charge la synthèse vocale, xDrip peut vous annoncer oralement divers événements.

::: xdripitem Prononcer les valeurs <span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Si le téléphone a des capacités text-to-speech, il prononcera chaque nouvelle lecture.
:::

Lorsque vous activez cette fonction, si la synthèse vocale n'est pas déjà présente sur votre appareil, vous devrez l'installer depuis le [Google Play Store](https://play.google.com/store/apps/details?id=com.google.android.tts) ou la boutique d'applications du fabricant de votre téléphone.

::: xdripitem Installer les données Text-To-Speech?
Installer les données Text-To-Speech?  
(Après l'installation des langues, vous devrez peut-être appuyer sur "Redémarrer le collecteur" dans État du système.)  
Non &emsp;&emsp;&emsp;OK
:::

Vous pouvez choisir d'entendre votre glycémie dans certaines conditions (variation supérieure à un certain seuil) ou à intervalles réguliers.

::: xdripitem Lors de changements par (0 mgdl ou mmol/l)
:::

::: xdripitem Ou par nombre de minutes (0)
:::

Les alertes peuvent aussi être prononcées si vous activez cette option.

::: xdripitem Prononcer les alertes <span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Donner également des messages d'alerte prononcées
:::

Vous pouvez faire prononcer la tendance, et faire répéter deux fois les valeurs ou toutes les informations prononcées.

::: xdripitem Prononcer le nom de la flèche de tendance <span class='symbol'><img src="../images/EN.png" style="zoom:75%;" /></span>
:::

::: xdripitem Prononcer la valeur de glycémie deux fois <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
:::

::: xdripitem Prononcer tout deux fois <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
:::

Si vous voulez imposer une autre langue pour les annonces, vous pouvez la choisir en saisissant manuellement le code [ISO639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) de la langue (par exemple `de`), suivi éventuellement d'un tiret bas (`_`) et d'un code régional défini par [ISO3166-1 alpha 2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements) (par exemple `en_IN`).

::: xdripitem Paramètres régionaux utilisés pour les lectures énoncées, par exemple : fr ou en_IN
:::

Vous pouvez modifier le ton de la voix et la vitesse de lecture.

::: xdripitem Vitesse de prononciation
:::

::: xdripitem Ton de la voix
:::

Et, si vous le souhaitez, ajouter un raccourci dans le menu principal.

::: xdripitem Raccourci pour les lectures prononcées <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
&ensp;Afficher un raccourci dans le menu ☰ pour gérer les prononciations de lectures
:::
