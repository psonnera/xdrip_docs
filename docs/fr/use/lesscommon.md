### Ligne d'état supplémentaire {#extra-status-line}

En haut à gauche de votre graphique principal se trouve la ligne d'état standard.  
Ce menu vous permet d'ajouter des informations supplémentaires dans cette zone.

::: xdripitem Ligne d'état supplémentaire
&ensp;Options pour la ligne supplémentaire
:::

Vous devez activer la ligne d'état supplémentaire pour ajouter des informations.

::: xdripitem Ligne d'état supplémentaire <span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Statut de texte supplémentaire
:::

Vous pouvez faire calculer certaines statistiques sur les dernières 24 heures. Par défaut, elles commencent à minuit.

::: xdripitem Fenêtre coulissante <span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>

### Maintenance automatique de la base de données {#database-automatic-maintenance}

Enregistrer la base de données tous les jours exporte réellement le fichier de base de données chaque jour avant le nettoyage. Cela occupe beaucoup de mémoire sur votre appareil et n'est pas recommandé.

Les exports de la base de données sont enregistrés dans le même dossier que les exports manuels : `/storage/emulated/0/xDrip` ou `Internal Storage/xDrip`.

::: xdripitem Enregistrer la base de données tous les jours <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
&ensp;Permet au Service d’intention quotidienne de sauvegarder la base de données avant la purge
:::

#### Rétention des glycémies {#glucose-retention}

Rétention des glycémies supprime automatiquement les données plus anciennes que le nombre de jours choisi.  
Zéro signifie ne rien supprimer. La valeur par défaut est de 180 jours : une nouvelle installation supprime donc automatiquement les données de plus de 180 jours, sauf si vous modifiez ce réglage. Vous pouvez choisir 90 jours si vous utilisez une sauvegarde dans le cloud comme Nightscout, tout en gardant toutes les statistiques disponibles dans xDrip.

::: xdripitem Rétention des glycémies
&ensp;Effacer les données antérieures à ce nombre de jours. 0 = ne rien effacer
:::
