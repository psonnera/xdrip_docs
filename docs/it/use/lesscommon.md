### Manutenzione automatica del database {#database-automatic-maintenance}

Salva il Database ogni giorno esporta effettivamente il file del database ogni giorno prima di fare pulizia. Occupa molta memoria del dispositivo e non è consigliato.

Le esportazioni del database vengono salvate nella stessa cartella delle esportazioni manuali: `/storage/emulated/0/xDrip` o `Memoria interna/xDrip`.

::: xdripitem Salva il Database ogni giorno <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
&ensp;Consente al servizio di pulizia giornaliero di salvare il database prima di svuotarlo
:::

#### Ritenzione del glucosio {#glucose-retention}

Ritenzione del glucosio elimina automaticamente i dati più vecchi del numero di giorni selezionato.  
Zero significa non eliminare nulla. Il valore predefinito è 180 giorni, quindi le nuove installazioni eliminano automaticamente i dati più vecchi di 180 giorni, a meno che tu non lo modifichi. Puoi usare 90 giorni se usi un backup nel cloud come Nightscout, così avrai comunque tutte le statistiche disponibili in xDrip.

::: xdripitem Ritenzione del glucosio
&ensp;Elimina vecchi dati. Tenere solo gli ultimi n giorni. 0 = non cancellare nulla
:::
