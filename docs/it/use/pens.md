### Penna per insulina NovoPen {#novopen-insulin-pen}

xDrip può scaricare le dosi dalle NovoPen 6 e Echo Plus.

Alcune note sull'implementazione [qui](https://github.com/NightscoutFoundation/xDrip/issues/2074).

### Penna per insulina InPen {#inpen-insulin-pen}

xDrip può scaricare le dosi dalla penna.

Potrebbe non funzionare con le [penne più recenti](https://github.com/NightscoutFoundation/xDrip/issues/1176).

### Penna per insulina Pendiq 2.0 {#pendiq-20-insulin-pen}

xDrip può leggere e scrivere le dosi.

Potrebbe non funzionare con le [penne più recenti](https://github.com/NightscoutFoundation/xDrip/issues/239).
