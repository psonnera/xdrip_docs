Se il tuo telefono supporta la sintesi vocale, xDrip può leggerti ad alta voce vari eventi.

::: xdripitem Letture Vocali <span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Se il telefono è dotato di lettura vocale, leggerà ogni nuova lettura
:::

Quando attivi la funzione, se la sintesi vocale non è già presente sul dispositivo dovrai installarla dal [Google Play Store](https://play.google.com/store/apps/details?id=com.google.android.tts) o dallo store del produttore del telefono.

::: xdripitem Installare i dati da sintesi vocale?
Installare i dati da sintesi vocale?  
(Dopo l'installazione delle lingue potresti dover premere "Riavvia Collector" in Stato del sistema.)  
No &emsp;&emsp;&emsp;OK
:::

Puoi scegliere di ascoltare il valore della glicemia in condizioni specifiche (variazioni oltre una certa soglia) o periodicamente.

::: xdripitem Quando cambia di (0 mgdl o mmol/l)
:::

::: xdripitem Oppure per minuti (0)
:::

Se lo attivi, anche gli avvisi possono essere letti ad alta voce.

::: xdripitem Pronuncia allarmi a voce alta <span class='symbol'><img src="../images/OFF.png" style="zoom:75%;" /></span>
&ensp;Fornisci anche alcuni messaggi di avviso vocali
:::

Puoi far pronunciare la tendenza e far ripetere due volte le letture o tutte le informazioni vocali.

::: xdripitem Pronuncia a voce alta la freccia di tendenza della glicemia <span class='symbol'><img src="../images/EN.png" style="zoom:75%;" /></span>
:::

::: xdripitem Leggi due volte a voce alta il valore del glucosio <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
:::

::: xdripitem Pronuncia a voce alta due volte <span class='symbol'><img src="../images/DIS.png" style="zoom:75%;" /></span>
:::

Se vuoi forzare le letture in un'altra lingua, puoi selezionarla inserendo manualmente la lingua con il codice [ISO639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) (ad esempio `de`) e, facoltativamente, un trattino basso (`_`) seguito da un'impostazione locale definita secondo [ISO3166-1 alpha 2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements) (ad esempio `en_IN`).

::: xdripitem Usa la lingua locale per le letture a voce alta, es: it o en_IN
:::

Puoi modificare il tono della voce e la velocità di lettura.

:::

::: xdripitem Tonalità della voce
:::
