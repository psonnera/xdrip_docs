### Unità di Misura Glicemia {#glucose-units}

::: xdrip Unità di Misura Glicemia
&emsp;<img src="https://raw.githubusercontent.com/NightscoutFoundation/xDrip/master/app/src/main/res/drawable-xhdpi/ic_ruler_grey600_48dp.png" style="width:5%;" />&ensp;mmol/l o mg/dl alta e bassa
:::

In questo menu puoi selezionare le unità usate da xDrip (mg/dl o mmol/l) e impostare gli obiettivi alto e basso.  

::: xdripitem Unità di Misura Glicemia
&ensp;mg/dl o mmol/l
:::

Questi due obiettivi stabiliscono quando i punti della glicemia sul grafico cambiano colore sopra o sotto l'obiettivo.

::: xdripitem Valore Massimo
&ensp;170
:::

::: xdripitem Valore Minimo
&ensp;70
:::
