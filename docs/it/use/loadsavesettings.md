::: xdripitem Carica / Salva impostazioni su memoria SD
Qui è possibile salvare le impostazioni per l'archiviazione esterna (sdcard).  
Una volta salvato l'archiviazione esterna è potenzialmente possibile per qualsiasi applicazione di leggere le impostazioni che potrebbero contenere informazioni sensibili.  
Si consiglia di eliminare le impostazioni una volta che li avete importato di nuovo, se siete preoccupati per questo.  
:::
    

### Salvare le impostazioni {#save-settings}

<div style="background-color: gray; color: white; text-align: center;">  &emsp;Salvare tutte le impostazioni nella SDcard&emsp;</div> 

Le impostazioni vengono salvate in `/storage/emulated/0/Download/xDrip-Export` nelle versioni vecchie (esportazione su SD) o nella cartella `Download/xDrip-export` nelle versioni recenti.   
Devi autorizzare xDrip ad accedere alla memoria del telefono.  

::: warning Il file di backup esistente verrà sovrascritto
:::

<img src="./images/M-S-LSSe.png" style="zoom:75%;" />

Se vuoi conservarne una copia sicura, inviati il file per email, salvalo su un cloud oppure copialo su un computer tramite USB.

### Caricare le impostazioni {#load-settings}

<div style="background-color: gray; color: white; text-align: center;">  &emsp;Caricare tutte Impostazioni dalla SDcard&emsp;</div> 

::: warning Le impostazioni esistenti verranno sovrascritte
:::

Potrebbe essere necessario riavviare il telefono per completare l'operazione.

### Eliminare le impostazioni {#delete-settings}

<div style="background-color: gray; color: white; text-align: center;">  &emsp;Eliminare impostazioni dalla SDcard&emsp;</div> 

Le impostazioni esportate contengono informazioni private: una volta trasferite su un altro telefono o in un luogo sicuro, potresti voler eliminare il backup.
