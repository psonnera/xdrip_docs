# Importare le impostazioni per Libre 2 diretto CON calibrazione {#importing-settings-for-libre-2-direct-with-calibration}

<img src="./images/qr_libre2direct-calib.png" style="zoom:60%;" />

Scansiona il codice QR qui sotto per caricare le impostazioni necessarie per Libre 2 diretto. In Impostazioni, nel menu "hamburger" a sinistra, seleziona "Configurazione automatica" e inquadra il codice QR. Dovrai toccare il pulsante Si per confermare che vuoi importare queste impostazioni.

## Impostazioni di Libre 2 diretto importate dal codice QR... {#libre-2-direct-settings-imported-from-qr-code}
