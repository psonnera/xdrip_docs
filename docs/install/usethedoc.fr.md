Cette documentation est basée sur la [dernière Nightly Build](https://github.com/NightscoutFoundation/xDrip/releases) (comptez quelques jours de décalage après une publication).  


## **Si vous découvrez xDrip**

Pour une première installation, continuez vers ⇒ [prérequis](../prerequisites) et suivez le parcours.

## **Si vous utilisez déjà xDrip** 

Si une fonction décrite ici n'apparaît pas dans votre application, vous devez peut-être [mettre à jour](../../use/update) xDrip.  
La version pour laquelle chaque page a été rédigée est indiquée en bas de page : une version plus ancienne peut ne pas inclure la fonction.

</br>

!!!info  
    Les fonctions du mode ingénieur ne sont volontairement pas documentées.

</br>

### Documentation d'origine

Cette documentation rassemble plusieurs sources : lorsque c'est le cas, vous trouverez des liens vers la **documentation d'origine et de référence**.  
Fiez-vous toujours à la documentation d'origine, sauf si elle est obsolète (ce sera indiqué).

### Traduction

La documentation est disponible en anglais, en français et en italien. Utilisez le sélecteur de langue en haut de la page pour changer de langue : vous restez sur la même page.  
Les traductions sont en cours : les pages pas encore traduites s'affichent en anglais, avec un avertissement. L'anglais est la version de référence ; une page traduite dont la version anglaise a changé depuis est signalée.

Les noms des menus et des paramètres sont ceux affichés par xDrip en français. Si votre xDrip est en anglais, la [version anglaise](../../../install/usethedoc/) de la documentation vous sera plus facile à suivre.

### Recherche

Vous pouvez rechercher un menu ou un terme dans la documentation avec la loupe en haut à droite, dans la langue que vous lisez.

### Faute, erreur, information manquante

Vous pouvez aussi contribuer en créant une [pull request](https://github.com/xdrip/xdrip_docs/pulls) dans le dépôt principal.

Vous pouvez également donner votre avis dans le groupe Facebook principal [xDrip](https://www.facebook.com/groups/xDripG5) (GitHub reste recommandé).
