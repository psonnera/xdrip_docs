### G7 or ONE+

This describes how to connect a Dexcom G7 or ONE+ sensor directly to xDrip. Sensor and transmitter are a single disposable unit, and from xDrip's perspective G7 and ONE+ are the same device — every step below applies equally to both.

For G6 or Dexcom ONE, see the [separate G6, Dexcom ONE page](../g6) instead.

!!!note  
    Some of this also applies to Stelo when connected directly to xDrip — check the [data source guide](../datasource) for current Stelo support.

#### Prerequisites

- Check your phone setup matches xDrip [prerequisites](./prerequisites.md) (time sync, battery optimization).
- Make sure xDrip is updated to at least the 2026.05.06 release.
- Only one app can collect from the sensor: uninstall the Dexcom app if xDrip is to be the collector. If you need to keep the Dexcom app, only it can collect — use xDrip as a [Companion app](../companion) follower instead. The same applies to the BYOD G7 app, which cannot broadcast to xDrip directly.

!!!info "t:slim / receiver order matters"  
    Connect with xDrip **first**. If a pump or receiver connects to the sensor before xDrip, xDrip will not be able to connect to it — if one is already running, disable it and wait 15 minutes.

!!!warning "Don't pair from Android Bluetooth settings"  
    Never pair the sensor from the Android Bluetooth settings page — let xDrip trigger the pairing request, and approve it when asked.

#### Starting the sensor

Insert the sensor following the manufacturer's applicator instructions. The session starts by itself the moment the sensor is inserted — there is nothing to start (or stop) in xDrip.

Take note of the 4-digit pairing code shown on the applicator; you'll need it next. If you're wearing two sensors during a changeover, mark the old one with a pen so you don't peel off the wrong one later.

#### Connecting xDrip to the sensor

1. In Android Settings → Connected devices, forget any devices named `DXCM**`, `DX01**` or `DX02**` (where `**` is any two characters), if listed.
2. Keep previously used sensors 10+ metres away or shielded (a metal box works).
3. Enter the 4-digit pairing code from the applicator:

!!!xdrip "<img src="../../images/hamburger_menu.png" style="zoom:75%;" />"  
    &ensp;Settings  
    &emsp;Dexcom Transmitter ID

Watch the [Dex Status page](../../troubleshoot/systemstatus) and approve the pairing request when it appears. If the sensor was inserted more than 30 minutes ago you should see readings right away; if just inserted, it shows as warming up and the status page fills in over time. Once battery voltages appear, it's safe to re-enable your pump or receiver.

#### Grace period

A G7/ONE+ runs 10 days plus a 12-hour grace period — 10.5 days total. Use the extra 12 hours as a changeover buffer, or to overlap sensors (presoak): a new G7's first hours are its least stable, so inserting the next sensor before the old one ends gives smoother readings at switchover.

#### Starting a subsequent sensor

Switching to a new sensor is only a code change:

1. Insert the new sensor around day 10 of the old one (see [Starting the sensor](#starting-the-sensor)).
2. When ready to switch, enter the new sensor's 4-digit pairing code as the [transmitter ID](#connecting-xdrip-to-the-sensor) and approve the new pairing request.

Two useful tips:

- If the old sensor still shows as a `DXCM**` device in your Android Bluetooth history, forget it there.
- Disable collection in xDrip *before* peeling off the old sensor — otherwise it may record one last, very low reading as the sensor leaves your skin.

!!!info "Pump or receiver users"  
    Disable the pump/receiver connection first, let xDrip connect to the new sensor, and re-enable the pump once readings are stable. If the sensor won't connect, wait 15 minutes for [rapid reconnect mode](../../troubleshoot/g7/#g7-rapid-reconnect-mode) to kick in.

#### Unknown firmware

If the firmware version on the [System Status](../../troubleshoot/systemstatus) page is flagged as unknown, you're most likely running an outdated xDrip — update to the latest release first. If the newest release still flags it, please report it in the [GitHub discussions](https://github.com/NightscoutFoundation/xDrip/discussions).
