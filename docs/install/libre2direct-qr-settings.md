# Importing Settings for Libre 2 Direct WITHOUT calibration

<img src="./images/qr_libre2direct-nocalib.png" style="zoom:60%;" />

Scan the QR code shown here to load the settings needed for Libre 2 direct. Under Settings in the left-hand "hamburger" menu, select "Auto configure" and capture the QR code. You will need to press the Yes button to confirm that you want to import these settings.

# Libre 2 Direct settings imported from QR code...

Scanning the QR code will result in the following settings & values.
These are the settings changes needed for correct Libre 2 direct operation.

- Hardware Data Source = Libre Bluetooth
- NFC Scan features → Use NFC feature = enabled
- NFC Scan features → Starting Bluetooth connection with Libre2 sensors = Always connect to Libre2 sensors
- NFC Scan features → Use faster multi-block reading method = disabled
- NFC Scan features → Use any-tag optimized reading method = disabled
- Less common settings → Advanced settings for Libre 2 → Show raw values in graph = enabled
- Less common settings → Advanced settings for Libre 2 → Show sensor info in Status = enabled
- Less common settings → Other misc. options → Out of process Libre algorithm = disabled
- Less common settings → Other misc. options → OOP2 algorithm calibration = No calibration
- Less common settings → Other misc. options → Smooth Libre data = enabled
- Less common settings → Other misc. options → Retrieve Libre history = enabled
- Less common settings → Bluetooth Settings → Turn Bluetooth on = enabled
- Less common settings → Bluetooth Settings → Allow BluCon unbonding = enabled
- Less common settings → Bluetooth Settings → Bluetooth Watchdog = enabled
- Less common settings → Bluetooth Settings → Trust Auto-Connect = enabled
- Less common settings → Bluetooth Settings → Use Background Scans = enabled
- Less common settings → Bluetooth Settings → Close GATT on BLE disconnect = disabled
