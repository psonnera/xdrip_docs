# Importing Selected Bluetooth Settings for Libre 2 Direct for SAMSUNG phones

<img src="./images/qr_libre2direct_samsung.png" style="zoom:60%;" />

Scan the QR code shown here to load the settings needed for Libre 2 direct. Under Settings in the left-hand "hamburger" menu, select "Auto configure" and capture the QR code. You will need to press the Yes button to confirm that you want to import these settings.

# Libre 2 Direct settings imported from QR code...

Scanning the QR code will only change the following 3 settings. 

- Less common settings → Bluetooth Settings → Use scanning = disabled
- Less common settings → Bluetooth Settings → Trust Auto-Connect = disabled
- Less common settings → Bluetooth Settings → Use Background Scans = disabled
