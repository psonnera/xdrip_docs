 Paramètres
  Lecteurs de Glycémie


Lecteur NFC ​

Si vous utilisez un lecteur Glucomen Aero avec un téléphone équipé d'un lecteur NFC, vous pouvez le scanner pour récupérer la dernière mesure.

Utiliser le lecteur NFC

 Télécharger les enregistrements de glucose à partir du lecteur NFC lorsque xDrip est ouvert

Si vous utilisez un lecteur Bluetooth compatible ​

Pour pouvoir activer Utiliser un lecteur Bluetooth, vous devez d'abord appairer un lecteur Bluetooth.
S'il s'agit d'un lecteur neuf, assurez-vous d'avoir mesuré votre glycémie au moins une fois avant d'essayer de l'appairer.

N'activez pas encore l'option de lecteur Bluetooth dans xDrip.

Utiliser un lecteur Bluetooth

 Automatiquement connecter et extraire des données d'un lecteur de glycémie compatible standard comme le Contour Next One

Recherche du lecteur Bluetooth :

Scanner pour trouver un lecteur Bluetooth

Mettez votre lecteur en mode appairage et appuyez sur Balayage dans le menu Scanner pour trouver un lecteur Bluetooth.

Une fois l'appairage effectué, vous pouvez activer le lecteur dans le menu.

Utiliser un lecteur Bluetooth

 Automatiquement connecter et extraire des données d'un lecteur de glycémie compatible standard comme le Contour Next One

Votre lecteur s'affiche maintenant en dessous :

Scanner pour trouver un lecteur Bluetooth

 Bayer HealthCare LLC AA:BB:CC:DD:EE:FF:00

Vous pouvez activer des sons pour signaler la connexion, la déconnexion et la récupération des données.

Indicateurs d’effets sonores

 Cocher pour jouer des effets sonores lorsque le compteur se connecte, se déconnecte ou synchronise les données

xDrip peut vous proposer d'utiliser le résultat pour étalonner votre capteur connecté (s'il accepte l'étalonnage).

Utiliser Meter pour les Calibrations

 Lorsqu'une nouvelle glycémie est reçue, demander si elle doit être utilisée pour calibrer

Il n'est pas recommandé d'activer l'étalonnage automatique.

Calibration automatique

 Calibrer en utilisant de nouvelles lectures de glycémie si les conditions semblent correctes sans demander confirmation (expérimental)

Lorsque vous activez l'utilisation du lecteur Bluetooth, toutes les glycémies capillaires sont automatiquement transférées dans xDrip en tant que traitements.
